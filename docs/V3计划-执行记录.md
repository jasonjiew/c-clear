## 关键实现决策与踩坑

1. **LiveCharts2 接入**：App TFM 需升到 `net8.0-windows10.0.19041`（SkiaSharp.Views.WPF 3.x 最低 Win10 19041，否则回退 net46x 资产触发 NU1701——TreatWarningsAsErrors 下为错误）。
2. **LiveCharts2 两个实测坑**（复现工程二分定位）：
   - 运行时**整体替换 Axis[] 数组**会破坏测量缓存（Y 轴标签堆叠、网格线压缩顶部）→ 改为“构造一次 + 原地更新”（TrendChartModel）；
   - 控件**可用高度 <150px** 时 Y 轴布局错乱 → 两处趋势图最小高度提至 140/150px；
   - WPF 模板默认白底 → `Background="Transparent"` 适配深色主题。
3. **图标枚举运行时校验**：`strings`/`grep` 对 Wpf.Ui.dll 有假阳性（`Download24` 二进制里存在但枚举中没有）——本会话起以 **WPF 反射探针**（`%TEMP%\lcprobe`）为唯一权威：`ArrowDownload24`/`Wand24`/`GridDots24` 等均经反射确认。
4. **亿赛通加密**：`dotnet new` 产物（csproj）被加密，Edit/Write 工具拒绝 → 删除后重写明文；PowerShell 写出的文件 node/Python 读到密文 → 截图处理统一走 Python。
5. **WPF 离屏渲染与 LiveCharts**：RenderTargetBitmap 离屏截图对 LiveCharts 可用（--screenshot-tour 兼容），但入场动画会截到中间态 → 图表动画速度降到 250ms。
6. **P5 真机误报迭代**（产品红线“不代删用户数据”）：
   - v1：`C:\ProgramData\Microsoft`、`USOShared` 等系统目录被报 → 增加系统数据目录名单；
   - v2：kingsoft/QQ/Mozilla 等已安装应用被报 → 注册表证据扩展 DisplayName/Publisher 包含匹配；
   - v3：**钉钉正在运行**（装在 `D:\...\DingDing`，数据目录 `Roaming\DingTalk` 拼写不同、位置/名称证据全不命中）→ 增加**运行中进程名匹配**（最强活跃信号）。
   - 另修复 `BuildReportOnlyCategory` 忽略叶子模式导致 `D:\found.*` 报整盘（356GB）的潜在误报。
7. **P3 数据安全案例**：本机 `D:\tmp` 实际存放 419 个用户工作文档——多盘 temp 规则因此定为 **Manual 级**（UI 永不默认勾选、自动清理永不触碰），且剔除 `tmp` 路径只保留 `Temp`。第一轮 E2E 曾把 D:\Temp+D:\tmp 内容扫入计划（未执行删除，仅 2MB 测试文件被回收后还原）。
8. **探针大小写事故**：E2E 排查中“类别缺失”实为探针程序 `RuleId == "d-drive-temp"` 大小写写错（实际 id `D-drive-temp`）——分析器逻辑本身正常；记录在此避免后人重复踩坑。
9. **HTML 周报用内联 SVG 替代 base64 PNG**（计划偏差）：Core 免引 SkiaSharp、矢量清晰、自包含效果等价。
10. **Pro 徽标可点击**：5 处 Pro 徽标（清理横幅/卸载残留/高级触发/周报/下载重复）均为按钮，点击弹 Pro 引导卡（¥49 买断 + 仓库链接 + 激活方式），绝无主动弹窗。
